# Django-проект для ПЗ 3 и ПЗ 4

Репозиторий содержит учебный Django-проект по дисциплине «Структура программного обеспечения и базы данных».
Проект сделан как продолжение двух практических работ: сначала была настроена авторизация пользователей, затем добавлены собственные модели, миграции, административная панель и запросы через Django ORM.

## Кратко о проекте

В проекте есть приложение `accounts`. Оно отвечает за пользовательские страницы, регистрацию, профиль и работу с учебными сущностями: факультетами, курсами и профилями студентов.

Основные возможности:

- регистрация нового пользователя;
- вход и выход из учетной записи;
- доступ к профилю только после авторизации;
- стандартная административная панель Django;
- модели с отношениями `OneToOneField`, `ForeignKey` и `ManyToManyField`;
- вывод списка курсов на отдельной странице;
- тесты для проверки авторизации и ORM-связей.

## Как запустить

Клонировать проект:

```bash
git clone https://github.com/ashleyrossmith17/PZ3.git
cd PZ3
```

Создать и активировать виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Подготовить базу данных:

```bash
python manage.py migrate
```

Создать пользователя администратора:

```bash
python manage.py createsuperuser
```

Запустить сервер разработки:

```bash
python manage.py runserver
```

После запуска проект открывается по адресу:

```text
http://127.0.0.1:8000/
```

## Модели приложения

В `accounts/models.py` описаны три модели:

- `Department` - факультет или направление;
- `Course` - курс, относящийся к факультету;
- `StudentProfile` - профиль студента, связанный с пользователем Django.

Связи между таблицами:

```text
User 1 : 1 StudentProfile
Department 1 : N Course
StudentProfile N : M Course
```

Для модели `Course` добавлено поле `description`, поэтому в проекте есть две миграции приложения `accounts`:

- `0001_initial.py` - создание основных моделей;
- `0002_course_description.py` - добавление описания курса.

## Что относится к ПЗ 4

В четвертой практической работе проект был расширен работой с базой данных:

- добавлены модели `Department`, `Course`, `StudentProfile`;
- выполнены миграции для новых моделей;
- модели выведены в административную панель;
- для админки настроены поиск, фильтры и список отображаемых полей;
- через ORM созданы и проверены связанные данные;
- добавлена страница `/courses/`, которая получает данные через `Course.objects.select_related('department')`.

## Проверка проекта

Для быстрой проверки можно выполнить:

```bash
python manage.py check
python manage.py test
```

Тесты проверяют:

- открытие главной страницы;
- перенаправление неавторизованного пользователя со страницы профиля;
- регистрацию;
- вход пользователя;
- доступ к списку курсов только после авторизации;
- связи между моделями `Department`, `Course`, `StudentProfile` и `User`.

## Дополнительно

В репозиторий не добавлены локальная база `db.sqlite3`, виртуальное окружение и файлы отчетов. Их нужно создавать или прикладывать отдельно, потому что они не относятся к исходному коду проекта.
